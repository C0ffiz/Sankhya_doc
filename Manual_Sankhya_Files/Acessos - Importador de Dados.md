# Acessos - Importador de Dados

 **![Módulo](https://ajuda.sankhya.com.br/hc/article_attachments/42311145989911) Módulo:** Configurações > Avançado         **![Versão](https://ajuda.sankhya.com.br/hc/article_attachments/42311129526679) Versão disponível:** A partir da 4.12

---

Através dessa tela é possível liberar acessos para utilização do [Importador de Dados](https://ajuda.sankhya.com.br/hc/pt-br/articles/5874837664023-Importador-de-dados) conforme os perfis de importação. Na lateral esquerda da tela, filtre os **"Cadastros"** ou **"Movimentos"** que você deseja:

![acessos 5.png](https://ajuda.sankhya.com.br/hc/article_attachments/23443533060247)

Clicando no botão **"+Adicionar"**, você poderá selecionar os [Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios) ou [Grupos de Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596134-Grupo-de-Usu%C3%A1rios) cadastrados previamente no sistema:

![adicionar2.gif](https://ajuda.sankhya.com.br/hc/article_attachments/6328921164567)

**Observação:** aqui também serão considerados os [Grupos Adicionais](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios#abagruposadicionais) criados no Cadastro de Usuários.

Caso queira remover acesso de algum Usuário ou Grupo, basta acionar o botão **"Remover"**:

![remover2.gif](https://ajuda.sankhya.com.br/hc/article_attachments/6328924024471)

Ao clicar no botão ![visualizar acessos.png](https://ajuda.sankhya.com.br/hc/article_attachments/6328501416215) **"Visualizar Acessos"**, verifique quais acessos um determinado Usuário ou Grupo possui:

![acessos.gif](https://ajuda.sankhya.com.br/hc/article_attachments/6328925792919)

Após liberar acessos ao Usuário e/ou Grupo de Usuários, ele conseguirá visualizar, baixar e/ou importar todas as tabelas liberadas a ele ou ao seu grupo. No exemplo abaixo, foi realizada a liberação de acesso apenas aos **"Bairros"** para o usuário **"PEDRO"**; assim, quando ele acessar a tela Importador de Dados, estará disponível para ele somente essa tabela para importação:

![IMPORTADOR\_8.gif](https://ajuda.sankhya.com.br/hc/article_attachments/6329558366231)
