# CheckList de Contratos

![Módulo 36x36 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/42311365094167) **Módulo:** Imobiliária > Cadastros > Contratos   
![Versão - 32x32 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/42311365094935) **Versão disponível:** a partir da 3.31

---

Através desta tela você poderá controlar os itens para finalizar um Contrato, seja ele de **"Venda de Lote"**, **"Venda"**, **"Administração"**, **"Locação"** ou **"Rescisão de Locação"**.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360095653314)

Através do botão **"Importar Modelo de Checklist"** você poderá importar um Modelo de CheckList previamente configurado na tela [Modelos de CheckList](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045378094) e, assim, a aba **"Itens do CheckList"** será preenchida automaticamente com todos os [Itens para CheckList](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045378134) vinculados à este Modelo: 

![check.gif](https://ajuda.sankhya.com.br/hc/article_attachments/360097953953)

**Observação:** caso você não deseje importar um Modelo de CheckList, nada impossibilitará que você vincule os Itens do CheckList de forma manual:

![check2.gif](https://ajuda.sankhya.com.br/hc/article_attachments/360097954073)
