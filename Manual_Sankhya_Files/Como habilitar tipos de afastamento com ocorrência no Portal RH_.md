# Como habilitar tipos de afastamento com ocorrência no Portal RH?

Para habilitar a visualização e o lançamento de afastamentos com ocorrência no Portal RH, siga os passos abaixo para realizar as devidas configurações no sistema.

  
 

### **Configuração de tipos de afastamento**

![](https://ajuda.sankhya.com.br/hc/article_attachments/39394564991255) Acesse a tela **"Ocorrências Pessoal+ » Rotinas Folha » Ocorrências"**  pesquise a descrição da ocorrência e localize o registro desejado.  
![](https://ajuda.sankhya.com.br/hc/article_attachments/39394564992663) Certifique-se de que o campo **"**Aparece no Portal RH**"** esteja marcado.

![](https://ajuda.sankhya.com.br/hc/article_attachments/41053794486807)  
![](https://ajuda.sankhya.com.br/hc/article_attachments/39394546639767) Clique no **"Botão Salvar"** para aplicar as alterações.  
 

### **Ajustes nas permissões do Portal RH**

Após configurar a ocorrência, certifique-se de que o perfil de acesso no Portal RH possui permissão para visualizar tais ocorrências.

![](https://ajuda.sankhya.com.br/hc/article_attachments/39394564991255) Acesse a tela **"Empresas"** (Configurações » Cadastros » Pessoal » Empresas) na aba Portal RH e verifique se as permissões de acesso. 

![](https://ajuda.sankhya.com.br/hc/article_attachments/41053817161367)  
![](https://ajuda.sankhya.com.br/hc/article_attachments/39394564992663) Caso necessário, revise os parâmetros que controlam a exibição de dados no portal para garantir que não haja restrições bloqueando a visualização.

Após realizar estas configurações, o sistema passará a considerar os tipos de afastamento definidos para exibição no Portal RH.
