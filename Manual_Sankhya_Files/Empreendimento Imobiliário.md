### Painel Principal

Localizado no alto da tela, o Painel Principal reúne os dados que servirão de base para todo o restante do cadastro dos Empreendimentos Imobiliários.

![emp2.png](https://ajuda.sankhya.com.br/hc/article_attachments/360091063894)

Informe no campo **"Empreendimento"** o nome de identificação do Empreendimento.

No campo **"Tipo do empreendimento"**, selecione um tipo de empreendimento que seja compatível com o Imóvel que será vinculado dentre as seguintes opções:

*   Caixa Econômica Federal;
*   Lote;
*   Shopping;
*   Casas;
*   Condomínio Fechado;
*   Prédio de Apartamentos;
*   Aluguel;
*   Apartamentos.

Se você desejar, poderá utilizar um **"Nome resumido"** para facilitar a identificação do Empreendimento.

No campo **"Estágio"** você seleciona o status do Empreendimento para o controle de etapa. Neste campo, temos as seguintes opções:

*   Aprovação;
*   Cadastro;
*   Cancelado;
*   Negociação;
*   Suspenso.

### Aba Geral

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360093229513)

Nos campos **"Dt. Lançamento"** e **"Dt. Entrega"**, selecione a data de lançamento e de entrega do Empreendimento, respectivamente.

Informe o **"Índice de Velocidade de Vendas"** para que você tenha um controle das vendas em relatórios.

Insira no campo **"Unidades"** a quantidade de Unidades que o Empreendimento possui.

Caso você habilite a marcação **"Lançamento"**, estará definindo que o Empreendimento é um lançamento, ou seja, novo.

Caso tenha um projeto criado para o Empreendimento, insira-o no campo **"Projeto"**.

No campo **"Conta corrente"** insira a conta vinculada ao Empreendimento.

Os campos **"Usuário Inclusão"** e **"Usuário Alteração"** serão preenchidos de forma automática, ao incluir ou alterar o Empreendimento.

Caso possua um projeto para correspondente bancário já criado para o Empreendimento, insira-o no campo **"Projeto Correspondente Bancário"**.

### Aba Localização

![mceclip2.png](https://ajuda.sankhya.com.br/hc/article_attachments/360093229993)

No campo **"Edifício"**, informe o [Edifício/Galeria](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045117013-Edif%C3%ADcios-e-Galerias) anteriormente cadastrado para o Empreendimento em questão.

O primeiro campo **"Endereço"** será preenchido automaticamente com o Endereço do Edifício/Galeria informado. Já o segundo Endereço, é para que você informe o Endereço correspondente ao Empreendimento.

Caso o Empreendimento possua algum complemento, informe-o no campo **"Complemento"**.

Informe também o **"Número"** do Empreendimento.

Preencha, por fim, o **"C.E.P."**, **"Bairro"** e **"Cidade"** onde localiza-se o Empreendimento.

### Aba Características

Nesta aba, informe as Características do Empreendimento para que elas sejam levadas, posteriormente, ao [Contrato de Venda de Lote](https://ajuda.sankhya.com.br/hc/pt-br/articles/360053745773-Contrato-de-Venda-de-Lote) e ao [Contrato de Locação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045117213-Contrato-de-Loca%C3%A7%C3%A3o), caso tenham sido configurados para serem apresentados na tela [Relatórios Formatados](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597694-Relat%C3%B3rios-Formatados).

### Aba Comissionamento

Nesta aba, você deve preencher as informações para que sejam geridos os Comissionamentos dos [Imóveis](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044608914-Im%C3%B3veis) vinculados ao Empreendimento.

![mceclip4.png](https://ajuda.sankhya.com.br/hc/article_attachments/360091091374)

No campo **"Gerente do empreendimento"**, selecione o Gerente anteriormente cadastrado na tela [Corretores](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045116973-Corretores).

### Aba Financiamento

![mceclip5.png](https://ajuda.sankhya.com.br/hc/article_attachments/360091091914)

Preencha o campo **"Máximo de parcelas"** com a quantidade máxima para as parcelas de financiamento.

Nos campos **"Índice até as chaves"** e **"Índice após as chaves"** informe o índice para correção periódica até e após a entrega das chaves do Imóvel, respectivamente.

Nos campos **"Juros até as chaves"** e **"Juros após as chaves"** insira o valor de juros para correção até e após a entrega das chaves do Imóvel, respectivamente.

Por fim, nos campos **"Periodicidade até as chaves"** e **"Periodicidade após as chaves"** informe a periodicidade para correção até e após a entrega das chaves do Imóvel, respectivamente.
