# Liberar o acesso ao aplicativo pessoas + para os funcionários

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19057163363223) **SITUAÇÃO:**

Para liberar o acesso ao aplicativo pessoas + para os funcionários, precisamos liberar dentro do sistema o acesso ao portal RH. Porém não são todos os funcionários que possuem acesso ao sistema. 

**![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18895844125591)SOLUÇÃO:**

Para o colaborador acessar o aplicativo do Pessoas + é necessário ter um Usuário do Sankhya OM cadastrado.

Esse usuário  é cadastrado na tela de **Usuários** _(Configurações » Controle de Acesso » Usuários)_, pois, é vinculado ao funcionário em questão e os acessos dos colaboradores são liberados na tela de "Acessos Pessoal Mais".
