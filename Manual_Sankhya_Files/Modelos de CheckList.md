Esta tela possibilita criar um Modelo de CheckList para ser utilizado na tela CheckList de Contratos, de forma a facilitar os novos lançamentos desta rotina.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360064275373)

No campo **"Tipo de Contrato"** você deverá escolher à qual tipo de contrato este Modelo e os Itens de Modelo de CheckList pertencerão:

*   Administração;
*   Venda;
*   Venda de Lote;
*   Rescisão de Locação;
*   Locação.

**Observação:** Os Itens de Modelo de CheckList deverão ser previamente cadastrados na tela [Itens para CheckList](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045378134).
