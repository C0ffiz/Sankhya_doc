# Resumo de Operações com Cartão

![Módulo 36x36 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/42312919982615) **Módulo:** Livros Fiscais > Arquivos

---

Esta tela possibilitará a inserção dos dados referentes aos registros 1600 e 1601 pelas operações realizadas com cartão.

Desse modo, informe inicialmente a **"Empresa"** e a data de referência no campo **"Referência"**.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/4419356823575)

Para o cadastro do Registro 1600, na aba **"Reg. 1600"**, preencha os campos **"Parc. Administradora"**, **"Valor das Vendas a Débito"** e **"Valor das Vendas a Crédito"**.

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/4419363110423)

Ressaltamos que, quando a marcação **"Gerar registro 1600 pelo Resumo de Operações com Cartão?"** da tela [EFD - Escrituração Fiscal Digital - ICMS/IPI](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607614-EFD-Escritura%C3%A7%C3%A3o-Fiscal-Digital-ICMS-IPI), aba [Opções](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044607614-EFD-Escritura%C3%A7%C3%A3o-Fiscal-Digital-ICMS-IPI#abaopes), estiver habilitada, o sistema utilizará os dados inseridos nesta tela (Resumo de Operações com Cartão) para tratar de forma manual as informações referentes ao Registro 1600 ao Gerar o arquivo.

Caso você deseje realizar o cadastro do Registro 1601, informe na aba **"Reg. 1601"**, o **"Parc. Administradora"** e o **"Parc. Intermediador"**.

![mceclip2.png](https://ajuda.sankhya.com.br/hc/article_attachments/4419363133463)

Além disso, preencha no campo **"Valor Bruto Vendas"** o valor total bruto referente as vendas e/ou prestação de serviços com incidência de ICMS, incluindo operações com imunidade do imposto.

No campo **"Valor Bruto Serviços"**, informe o valor total bruto referente a prestação de serviços com incidência de ISS.

Por fim, preencha o campo **"Valor Outros"** com o valor total de operações deduzindo os valores dos campos Valor Bruto vendas e Valor Bruto Serviços.

Lembrando que, quando a marcação **"Gerar registro 1601 pelo Resumo de Operações com Cartão?"** da tela EFD - Escrituração Fiscal Digital - ICMS/IPI, aba Opções, estiver habilitada, o sistema utilizará os dados inseridos nesta tela (Resumo de Operações com Cartão) para tratar de forma manual as informações referentes ao Registro 1601 ao Gerar o arquivo.
